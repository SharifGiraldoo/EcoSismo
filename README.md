# EcoSismo
Solución propuesta para el Rally Latinoámericano de Innovación 2026 que gestiona circularmente  la disposición de residuos electrónicos móviles mediante una app móvil escalable a todo tipo de dispositivos por medio de la cual los dispositivos recolectados sirven como estaciones sísmicas de alerta temprano y así mismo como una red de monitoreo portátil y sencilla de usar
